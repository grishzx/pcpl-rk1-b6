## Запуск

Нужен Python 3. Дополнительные библиотеки не требуются.
Откройте терминал в корневой папке проекта и выполните:

```bash
python RK1/main.py
```

В Windows также можно использовать `py RK1/main.py`,
а в Linux или WSL - `python3 RK1/main.py`.
Программа использует готовые тестовые данные: ввод с клавиатуры не нужен.

## Классы и связи

- `House` - дом: идентификатор, название, число этажей и ID основной улицы.
- `Street` - улица: идентификатор и название.
- `HouseStreet` - пара ID дома и ID улицы для связи многие-ко-многим.

Для связи один-ко-многим у каждого дома указана одна основная улица.
Для связи многие-ко-многим дом на пересечении улиц может относиться
сразу к нескольким улицам. Например, Дом купцов связан с Центральной и Лесной.

В списках 4 дома, 3 улицы и 5 связей. Названия и данные учебные.
Количество этажей - количественный признак дома; в запросах варианта Б
подсчитываются сами дома, поэтому число этажей в расчётах не используется.

## Запросы варианта Б

1. Б1: вывести пары «дом - основная улица», отсортированные по названию дома.
2. Б2: вывести все улицы и количество домов на каждой, отсортировав
   по возрастанию количества домов. При равных количествах сохраняется
   исходный порядок улиц.
3. Б3: для связи многие-ко-многим вывести дома, названия которых
   заканчиваются на «ов», и список их улиц.

Условие «фамилия сотрудника заканчивается на ов» перенесено на название дома:
например, «Дом купцов» и «Дом мастеров».

В решении используются списковые и словарное включения, `sorted`,
`lambda`, `len` и `endswith`.
